# Готовые дистрибутивы

| Файл | Для чего | Размер |
|---|---|---|
| `Ищейка-windows.zip` | Программа для Windows. Распаковать и запустить `Ищейка.exe`. Python не нужен | ~150 МБ |
| `Ищейка-0.1.0.apk` | Клиент для Android 7.0+. Нужен уже работающий сервер | 2,5 МБ |

Подробные инструкции — [../docs/УСТАНОВКА.md](../docs/УСТАНОВКА.md).

## Коротко

**Windows.** Распакуйте архив в любую папку, запустите `Ищейка.exe`. Откроется
браузер. Рядом с программой появится файл настроек `.env` — впишите в него
бесплатный ключ модели (`console.groq.com`), иначе отчёты будут
демонстрационными.

**Android.** Приложение — это клиент: сначала поднимите сервер и убедитесь,
что его адрес открывается в браузере телефона. Затем установите APK и введите
этот адрес. Android предупредит об установке из неизвестного источника — так
и должно быть, приложение распространяется внутри компании, а не через
Google Play.

## О подписи APK

Приложение подписано отладочным ключом. Оно устанавливается на устройства,
но не годится для публикации в магазине. Для Google Play нужен свой ключ
подписи — см. раздел «Сборка из исходников» в инструкции по установке.
